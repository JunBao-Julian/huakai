## 一、准备：边改边看效果

需要先安装 [Node.js](https://nodejs.org/)（20 或更高版本）。在项目文件夹里打开终端：

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>。之后**每次保存代码文件，页面会自动刷新**。

没有摄像头或不想每次都举手：勾选右下角 **手动模式**，拖滑块看 0%（花苞）、50%（半开）、100%（盛开）三种状态。**改形状时三种状态都要看一下**，有些参数只影响花苞，有些只影响盛开。

## 二、改花瓣颜色

### 1. 主颜色渐变 —— `src/flower/Flower.ts` 第 274~280 行

```ts
const petalTex = petalTextures([
  [0, '#f7f0d8'],    // 花瓣根部（靠近花心）：奶白
  [0.18, '#fbe8e6'],
  [0.5, '#f7c3d2'],  // 花瓣中部：浅粉
  [0.8, '#ee8fb0'],
  [1, '#d9638e'],    // 花瓣尖：深粉
]);
```

每一行是 `[位置, 颜色]`，位置 0 是花瓣根部，1 是花瓣尖，中间可以加任意多个颜色点。颜色用 `#RRGGBB` 十六进制写法（可在 <https://htmlcolorcodes.com/zh/> 取色）。

### 2. 光泽与透光色 —— 同文件第 291、293 行

```ts
sheenColor: new THREE.Color('#ffd6e4'),  // 丝绒般的高光颜色，取比花瓣浅一点的同色系
emissive: new THREE.Color('#ff7aa6'),    // 透光感颜色，取花瓣的主色
```

### 3. 花瓣边缘加深色、叶脉颜色 —— `src/flower/textures.ts` 第 61、65、69 行

```ts
side.addColorStop(0, 'rgba(190,40,90,0.22)');   // 左边缘加深色（r,g,b,透明度）
side.addColorStop(1, 'rgba(190,40,90,0.22)');   // 右边缘加深色
drawVeins(ctx, w, h, 'rgba(185,50,105,0.16)', 34, 1.6);  // 叶脉颜色、条数、粗细
```

换颜色时把这里也改成同色系的深色，否则边缘会残留粉色。

### 4. 每层花瓣的颜色微调

第 26~32 行每一层末尾的 `tint`，会和上面的渐变颜色**相乘**：`'#ffffff'` 表示不变，`'#fff0f4'` 表示稍微偏粉一点。想让内层更白/更深，改这里即可。

## 三、改花瓣层数、片数、大小、张开角度

核心配置在 `src/flower/Flower.ts` 第 26~32 行，**每一行是一层花瓣，第一行最外层**：

```ts
const LAYERS: LayerDef[] = [
  { n: 6, L: 1.3,  W: 0.5,  rb: 0.3,   pr: 0.13, py: 0.0,  tilt: 1.42, bend: 0.55, cup: 0.32, delay: 0.0,  tint: '#ffffff' },
  { n: 6, L: 1.2,  W: 0.46, rb: 0.255, pr: 0.11, py: 0.04, tilt: 1.18, bend: 0.38, cup: 0.42, delay: 0.08, tint: '#fff6f8' },
  ...
];
```

| 参数 | 含义 | 常用范围 | 调大会怎样 |
|---|---|---|---|
| `n` | 这一层花瓣数 | 3 ~ 8 | 花瓣更密 |
| `L` | 花瓣长度 | 0.4 ~ 1.5 | 花更大，花苞更高 |
| `W` | 花瓣半宽（最宽处的一半） | 0.2 ~ 0.6 | 花瓣更圆胖 |
| `rb` | **花苞**时这一层的半径 | 0.1 ~ 0.4 | 花苞更胖 |
| `pr` | **盛开**时花瓣根部离花心距离 | 0.03 ~ 0.15 | 花心更大 |
| `py` | 盛开时花瓣根部高度 | 0 ~ 0.15 | 内层更高，层次更分明 |
| `tilt` | 盛开时花瓣倾斜角（弧度）：0 竖直，1.57 水平 | 0.2 ~ 1.6 | 开得更平、更大 |
| `bend` | 盛开时花瓣尖外翻程度 | 0 ~ 0.6 | 花瓣尖更往下垂 |
| `cup` | 花瓣横向内凹（勺子形） | 0.2 ~ 1.0 | 花瓣更像小碗 |
| `delay` | 开放延迟（0~1） | 0 ~ 0.4 | 这一层更晚开 |
| `tint` | 颜色微调 | 见上一节 | — |

> 角度换算：弧度 = 角度 × 0.0175。例如 45° ≈ 0.79，60° ≈ 1.05，80° ≈ 1.4。

**加一层 / 减一层**：直接增删一行即可，代码会自动适应。

**⚠️ 三条规则（不遵守会出现花瓣互相穿插、闪烁）：**

1. `rb` 必须**从外到内依次变小**。
2. 相邻两层的 `rb` 差值要 **大于 `n × 0.007`**。例如外层 `n: 6`，那它和下一层的 `rb` 至少要差 0.042。原因：同一层的花瓣在花苞里会依次错开 0.007，避免互相穿插（第 302 行的 `i * 0.007`）。
3. `delay` 一般**从外到内依次变大**，最内层不要超过 0.4（否则开到 100% 时内层还没开完）。

**整体开放节奏** —— 第 39 行：

```ts
const SPAN = 0.62; // 每一层从开始开到完全开所占的进度
```

调小（如 0.4）每层开得更快、层次感更强；调大（如 0.8）所有层几乎同时开。注意：最大 `delay` + `SPAN` 应 ≤ 1，否则开到 100% 时最内层还没完全打开。

## 四、改花瓣形状

花瓣轮廓由第 46~51 行的 `petalWidth` 函数决定，输入 `v` 从 0（根部）到 1（尖端），输出这个位置的相对宽度（0~1）：

```ts
function petalWidth(v: number) {
  const c = 0.62;   // 最宽处的位置：调小 → 花瓣上半部分更长更尖；调大 → 更圆
  if (v < c) return 0.16 + 0.84 * Math.pow(Math.sin(((v / c) * Math.PI) / 2), 0.9);
  //               ↑ 根部宽度：0.16 很窄，调到 0.4 根部更宽
  const k = (v - c) / (1 - c);
  return Math.sqrt(Math.max(0, 1 - k * k));   // 圆形尖端
}
```

**尖头花瓣**（如百合、睡莲）：把最后一行换成

```ts
  return 1 - k * k * (0.3 + 0.7 * k);   // 尖端变尖
```

**花瓣边缘的波浪** —— 第 102 行：

```ts
this.ruffle = 0.02 + Math.random() * 0.03;
```

整体乘一个倍数即可，例如 `(0.02 + Math.random() * 0.03) * 3` 得到牡丹那样的大波浪；乘 `0` 则边缘完全平整。

### 花萼（花朵底下的 5 片绿色小叶）—— 第 34~36 行

```ts
const SEPAL: LayerDef = { n: 5, L: 0.62, W: 0.2, rb: 0.355, ... };
```

参数含义同花瓣层。**不要花萼**：把 `n: 5` 改成 `n: 0`。

### 叶子 —— 第 343~346 行

```ts
const leafSpecs = [
  { t: 0.42, rotY: 0.6, tilt: 0.95, L: 1.25, W: 0.3 },
  { t: 0.6,  rotY: 3.6, tilt: 1.05, L: 1.1,  W: 0.27 },
];
```

| 参数 | 含义 |
|---|---|
| `t` | 长在茎的什么位置（0 = 花下面，1 = 茎底部） |
| `rotY` | 朝哪个方向（弧度，0~6.28 绕一圈） |
| `tilt` | 叶子与茎的夹角，越大越平 |
| `L` / `W` | 长度 / 半宽 |

加一片叶子就加一行，删掉所有行就没有叶子。叶子颜色在 `src/flower/textures.ts` 第 88~90 行（三个绿色）。

### 茎 —— 第 328~335 行

`CatmullRomCurve3` 里的 5 个点是茎经过的位置（x, y, z），改 x/z 可以让茎更弯；`TubeGeometry(curve, 80, 0.048, 14)` 中的 `0.048` 是茎的粗细。

## 九、改完后重新打包发布

1. 本地确认效果：`npm run dev`，看花苞、半开、盛开三种状态。
2. 本地打包测试（可选）：Windows 上 `npm run dist:win`，在 `release/` 里得到 zip。
3. 提交并推送到 GitHub：
   ```bash
   git add -A
   git commit -m "换成郁金香"
   git push
   ```
4. 打开 GitHub 仓库 → **Actions** → 左侧 **build** → 右侧 **Run workflow**，约 5 分钟后在本次运行页面底部 **Artifacts** 下载 Windows 和 macOS 安装包。
5. 发布新版本：先把 `package.json` 里的 `"version"` 改大（如 `0.2.0`），再到仓库 **Releases → Draft a new release**，填写版本号（如 `v0.2.0`），把下载的安装包拖进去，点 **Publish release**。
