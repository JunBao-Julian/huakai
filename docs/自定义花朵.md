# 自定义花朵指南

[← 返回首页](../README.md)

## 一、content 文件夹在哪里

```
content/
├─ exhibit.json        展项设置：标题、轮流展示哪些花、各种时间、互动区、声音、管理密码
└─ flowers/
   ├─ lotus.json       荷花
   ├─ tulip.json       郁金香
   └─ peony.json       牡丹
```

| 环境 | 位置 |
|---|---|
| Windows 展机 | 程序文件夹里的 `content`（和 `HuaKai.exe` 在一起），直接改即可 |
| Mac | 默认使用程序内置内容。想修改：把本仓库 `public/content` 整个文件夹复制到 `~/Library/Application Support/huakai/content` 再改 |
| 开发 / 打包 | 本仓库的 `public/content`，打包时会一起带上 |

程序启动时依次查找：程序所在文件夹的 `content` → 用户数据目录的 `content` → 程序内置。当前用的是哪个，在管理面板「系统」一栏能看到。

> 用记事本以外的编辑器修改更稳妥，推荐 VS Code，它会标出 JSON 格式错误。文件需保存为 UTF-8 编码。

## 二、改知识卡文案

打开 `flowers/` 下对应的文件，修改 `name` 和 `knowledge`：

```json
"name": "荷花",
"knowledge": {
  "latin": "Nelumbo nucifera",
  "family": "莲科 莲属",
  "bloom": "6–9 月",
  "meaning": "清白、坚贞",
  "location": "3 号温室",
  "intro": "一段简介，建议 60~100 字。"
}
```

| 字段 | 知识卡上显示为 | 说明 |
|---|---|---|
| `name` | 大标题、盛开横幅“你唤醒了一朵 XX”、待机提示 | |
| `latin` | 学名（斜体） | |
| `family` | 科属 | |
| `bloom` | 花期 | |
| `meaning` | 花语 | |
| `location` | 在本中心 | **建议填写**，如“3 号温室”，把游客引向真花；留空 `""` 则这一行不显示 |
| `intro` | 简介段落 | |

> 内置三种花的 `location` 都是空的，请按中心实际种植位置填写。科普内容建议由园艺同事审核。

## 三、改花瓣颜色

在 `appearance` 里：

```json
"petalColors": [[0, "#f7f0d8"], [0.18, "#fbe8e6"], [0.5, "#f7c3d2"], [0.8, "#ee8fb0"], [1, "#d9638e"]],
"edgeColor": "#be285a",
"veinColor": "#b93269",
"sheenColor": "#ffd6e4",
"glowColor": "#ff7aa6"
```

| 字段 | 含义 |
|---|---|
| `petalColors` | 花瓣颜色渐变，每项 `[位置, 颜色]`：0 = 花瓣根部（靠近花心），1 = 花瓣尖；中间可加任意多个颜色点 |
| `edgeColor` | 花瓣左右边缘加深的颜色，取主色的深色 |
| `veinColor` | 花瓣叶脉颜色，取主色的深色 |
| `sheenColor` | 丝绒般的高光，取比花瓣浅一点的同色系 |
| `glowColor` | 透光感颜色，取花瓣主色 |

颜色用 `#RRGGBB` 写法，可在 <https://htmlcolorcodes.com/zh/> 取色。**最好对着中心真实花朵的照片取色**。

**示例：粉荷花改成白荷花**

```json
"petalColors": [[0, "#f4f1dc"], [0.3, "#fbfaf4"], [0.75, "#f6f2ee"], [1, "#e9dfe6"]],
"edgeColor": "#aaa096",
"veinColor": "#a0968c",
"sheenColor": "#ffffff",
"glowColor": "#fff6e0"
```

## 四、改花瓣层数、片数、大小、张开角度

`appearance.layers` 里**每一项是一层花瓣，第一项最外层**：

```json
"layers": [
  { "count": 6, "length": 1.3, "width": 0.5, "openAngle": 81, "tipCurl": 31, "cup": 0.32 },
  { "count": 6, "length": 1.2, "width": 0.46, "openAngle": 68, "tipCurl": 22, "cup": 0.42, "tint": "#fff6f8" }
]
```

| 字段 | 含义 | 常用范围 | 调大会怎样 |
|---|---|---|---|
| `count` | 这一层花瓣数 | 3 ~ 8 | 花瓣更密 |
| `length` | 花瓣长度 | 外层 1.0~1.3，内层依次变短 | 花更大，花苞更高 |
| `width` | 花瓣半宽（最宽处的一半） | 0.2 ~ 0.6 | 花瓣更圆胖 |
| `openAngle` | 完全张开时与竖直方向的夹角（**度**） | 外层 50~90，内层依次变小 | 开得更平、更大（90 = 水平） |
| `tipCurl` | 完全张开时花瓣尖外翻（度） | 0 ~ 35 | 花瓣尖更往下垂 |
| `cup` | 花瓣横向内凹（勺子形） | 0.2 ~ 1.0 | 花瓣更像小碗 |
| `tint` | 这一层的颜色微调，与花瓣颜色相乘 | `#ffffff` 为不变 | — |

**加一层 / 减一层**：直接增删一项即可。

以下参数**一般不用填**，程序会自动推算并保证花瓣不互相穿插：`budRadius`（花苞时这一层的半径）、`baseRadius`（张开时根部离花心距离）、`baseHeight`（根部高度）、`delay`（开放延迟，外层先开）。内置花朵填写了这些值，是为了精确还原调好的样子；新做的花可以不写。

**其它外观参数**

| 字段 | 含义 |
|---|---|
| `ruffle` | 花瓣边缘波浪强度：1 默认，0 完全平整，2~3 像牡丹那样的大波浪 |
| `span` | 每层从开始开到完全开所占的进度：小（如 0.5）层次感强，大（如 0.8）各层几乎同时开 |
| `sepals` | 花萼（花朵底部的绿色小叶）：`{ "count": 5 }`；不要花萼写 `false` |
| `stamens` | 花蕊：`{ "count": 120, "filamentColor": "#f3e3a0", "antherColor": "#e8a422", "pod": "#c9d46a" }`；`pod` 是花心的花托颜色，写 `false` 表示没有；不要花蕊写 `false` |
| `stamens.style` | `"lotus"`：莲花式，倒圆锥形莲蓬（顶面嵌着心皮）+ 外围一圈花蕊；不填为普通花蕊 |
| `stamens.pistil` | 雌蕊（子房 + 三裂柱头）的颜色，如郁金香 `"#cdd8a0"`；不需要就不填 |
| `petalShape` | 花瓣轮廓：`{ "tip": 0.6, "widest": 0.58, "base": 0.2 }`。`tip` 尖度，0 圆头（牡丹）~1 尖头；`widest` 最宽处在花瓣长度的哪个位置（0.3~0.85）；`base` 根部宽度 |
| `translucency` | 透光强度 0~1.5（默认 0.8）：逆光时花瓣透出的光，花瓣越薄可以越大 |
| `transmitColor` | 透光的颜色，一般取花瓣主色、更饱和一些 |
| `veins` | 花瓣叶脉条数（默认 70），莲花这种细密平行脉可以 90 左右 |
| `foliage` | 叶子：`"lotus"` 背景里的荷叶（茎上无叶）、`"tulip"` 带状长叶、`"leaves"` 茎上两片叶、`"none"` 无 |
| `stemColor` | 茎的颜色 |

花蕊还可以调：`radius`（分布范围，默认 0.1）、`length`（花丝长度范围，默认 `[0.2, 0.3]`）、`spread`（张开时散开角度，度，默认 57）、`antherSize`（花药大小倍数，默认 1）。

**参考**：内置的荷花是“4 层尖头船形瓣 + 莲蓬 + 荷叶背景”，郁金香是“2 层 × 3 片、杯形、无花萼、深色雄蕊 + 雌蕊”，牡丹是“3 层圆头波浪瓣的半重瓣 + 金黄雄蕊”，可以打开 `lotus.json`、`tulip.json`、`peony.json` 对照。

> 花瓣重叠很多、层数很密的花（比如重瓣牡丹、玫瑰）很容易出现花瓣互相穿插，看起来不真实。建议优先做层数少、结构清楚的花型。

## 五、展项设置（exhibit.json）

```json
{
  "title": "花开",
  "subtitle": "张开手掌，花朵绽放 · 握拳，花朵闭合",
  "flowers": ["lotus", "tulip", "peony"],
  "timing": { "leaveTimeout": 8, "bloomHold": 0.8, "cardDuration": 15, "breathPeriod": 6 },
  "vision": {
    "numHands": 2,
    "camera": { "width": 1280, "height": 720 },
    "zone": { "x": 0.1, "y": 0.0, "w": 0.8, "h": 1.0 },
    "minHandSize": 0.05,
    "calibration": { "closed": 1.15, "open": 1.85 }
  },
  "audio": { "volume": 0.6, "ambient": true },
  "admin": { "pin": "2580" },
  "kiosk": { "dailyRestart": "03:00" },
  "render": { "quality": "high" }
}
```

| 字段 | 含义 |
|---|---|
| `title` / `subtitle` | 屏幕顶部的标题和副标题 |
| `flowers` | 轮流展示哪些花、什么顺序，填 `flowers/` 下的文件名（不带 `.json`）。比如当季只展示牡丹：`["peony"]` |
| `timing.leaveTimeout` | 游客离开多少秒后复位换花 |
| `timing.bloomHold` | 手完全张开保持多少秒算“盛开” |
| `timing.cardDuration` | 知识卡显示多少秒 |
| `timing.breathPeriod` | 待机时花苞“呼吸”一次的秒数 |
| `vision.numHands` | 同时识别几只手（用来在多人中挑一只），一般 2 |
| `vision.camera` | 摄像头分辨率 |
| `vision.zone` | 互动区：画面中的位置和大小（0~1，镜像后的画面），建议在管理面板里拖动调整 |
| `vision.minHandSize` | 最小手掌尺寸，越大越只认站得近的人 |
| `vision.calibration` | 校准基准：握拳和张开时的手掌比值，一般不用改 |
| `audio.volume` / `audio.ambient` | 音量（0~1）、是否播放背景音乐 |
| `admin.pin` | 管理面板密码，填 `""` 则不需要密码（不建议） |
| `kiosk.dailyRestart` | 每日定时重启时间，如 `"03:00"`；填 `null` 关闭 |
| `render.quality` | 画面质量：`"high"` 全部效果（推荐有独立显卡或较新核显的电脑）；`"medium"` 关闭花瓣夹缝的阴影（环境光遮蔽）；`"low"` 只保留基础渲染，给性能较弱的电脑 |

> 管理面板里调过的互动区、校准、音量会保存在本机，并**优先于** exhibit.json。想让 exhibit.json 的设置生效，在管理面板点「清除本机所有调整」。

## 六、新增一种花

1. 复制一个最像的现有文件，比如 `flowers/tulip.json` → `flowers/lily.json`；
2. 修改 `id`（与文件名一致，如 `"lily"`）、`name`、`knowledge`、颜色和形状；
3. 在 `exhibit.json` 的 `flowers` 里加上 `"lily"`；
4. 重启程序（或在管理面板点「重新加载」）。

## 七、边改边看效果

**在展机上**：改完保存 → 管理面板「重新加载」→ 在「花朵」里切换到要看的花 → 勾选「手动模式」拖动滑块，看花苞、半开、盛开三种状态。

**预览模式**（开发电脑上用浏览器）：在地址后面加参数，可以不开摄像头、不显示界面，直接看某朵花的某个开度，方便对比修改前后：

- `http://localhost:5173/?preview&flower=lotus&open=1` —— 荷花完全盛开（会缓慢旋转）
- `http://localhost:5173/?preview&flower=peony&open=0.5&still` —— 牡丹半开，画面静止

`flower` 填花朵文件名，`open` 填 0（花苞）~1（盛开），加 `still` 表示不旋转、不摆动。

**在开发电脑上**（需要安装 [Node.js](https://nodejs.org/)）：

```bash
npm install
npm run dev
```

浏览器打开 <http://localhost:5173>，修改 `public/content` 里的文件后刷新页面即可。按 `Ctrl+Shift+A` 打开管理面板（开发模式不需要密码）。

**改形状时三种状态都要看**：有些参数只影响花苞，有些只影响盛开。

## 八、出错了怎么办

- 某个花朵文件格式写错（比如少了逗号）或数值超出范围，程序会**跳过这朵花**继续运行，并在日志里写明原因，例如“花朵 lily 加载失败：第 2 层 openAngle 应在 0~150 之间”。
- 所有花朵都加载失败时，程序会显示内置的荷花，展项不会黑屏。
- `exhibit.json` 写错时，程序使用默认设置运行，同样会记日志。
- 日志位置见管理面板「系统」一栏，或 [使用教程 · 日常运维](使用教程.md#六日常运维)。
- 改乱了想恢复：从本仓库 `public/content` 重新复制一份原始文件。
